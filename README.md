One short line about office life: my boss calls it an open-door policy,
but every time I walk in he closes his laptop like I just caught him
booking a holiday.

## Run

```sh
node main.ts
```

Writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to
`./output/entry.txt`), after self-validating the gate: exactly one line,
1–200 characters, no trailing newline.
